# 查看项目状态 📊 (状态机版)

---

## 🚀 快速查看

### 1. 查看状态机当前状态

```bash
node .claude/skills/我要干活了/scripts/state-manager.cjs get
```

显示内容：
- `currentState` - 当前状态
- `currentRQ` - 当前执行的需求
- `completedSteps` - 已完成的步骤
- `lastUpdated` - 最后更新时间

---

### 2. 查看HTML版本（推荐）

自动在浏览器中打开 `项目执行跟踪矩阵.html`：
- ✅ 美观的表格展示
- ✅ 清晰的状态标记
- ✅ 点击查看详细文档
- ✅ Git提交时间显示

---

### 3. 查看MD版本

直接读取 `项目执行跟踪矩阵.md`

## 📋 状态机状态说明

| 状态 | 说明 | 下一步 |
|------|------|--------|
| INIT | 初始状态，等待操作 | 新增需求 / 执行需求 |
| NEED_RQ_NUMBER | 需要分配RQ编号 | Brainstorming |
| NEED_BRAINSTORMING | 需要生成规格 | Writing-Plans |
| NEED_PLAN | 需要生成计划 | 创建分支 |
| NEED_BRANCH | 需要创建分支 | 执行任务 |
| EXECUTING_TASKS | 执行任务中 | 等待验证 |
| WAITING_VALIDATION | 等待用户验证 | 完成 |
| DONE | 需求完成 | 回到INIT |

## 🔧 快捷操作

### 重置状态机到INIT
```bash
node .claude/skills/我要干活了/scripts/state-manager.cjs reset
```

### 获取下一个RQ编号
```bash
node .claude/skills/我要干活了/scripts/state-manager.cjs next-rq
```

### 手动重新生成HTML
```bash
node .claude/skills/我要干活了/scripts/markdown-to-html.cjs 项目执行跟踪矩阵.md
```

## 💡 状态标记说明

### 需求状态标记
- ✅ 已完成 - 需求已实现并通过验证
- 🔄 执行中 - 需求正在开发中
- 🔄 n/m 任务完成 - 执行中，显示进度
- ⏳ 等待验证 - 任务完成，等待用户确认
- 📋 规格已完成 - 规格文档已生成
- 🚧 规划中 - 需求刚创建，等待规格
- ⏸️ 暂停 - 需求已暂停

### 合规检查标记（RQ-037起）
- ✅ 通过 - 遵守了所有七道门控
- ❌ 未执行 - 缺少某些门控步骤
- ⬜️ 豁免 - 有人类声明的豁免
- — - 不适用（v10之前的需求）
