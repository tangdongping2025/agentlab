## 🔧 初始化步骤

### 步骤1：检查现有状态

```bash
# 检查是否已有跟踪矩阵

# 检查是否有文档目录
ls -la docs/superpowers/ 2>/dev/null || echo "目录不存在"
```


## 📊 跟踪矩阵统计分类

| 类型 | 说明 |
|------|------|
| 总需求数 | 所有需求计数 |
| 已完成 | ✅ 状态的需求 |
| 进行中 | 🔄 执行中的需求 |
| 暂停 | ⏸️ 暂停的需求 |
| 待规划 | 🚧 规划中的需求 |

## 📋 v10状态机跟踪矩阵格式

```markdown
# Context Lab 项目执行跟踪矩阵

## 项目状态
- 项目名称：xxx
- 开始日期：2026-xx-xx
- 最后更新：2026-xx-xx
- 当前状态：xxx
- 流程版本：v10 状态机版

## 需求总体统计
- 总数：0
- 已完成：0
- 进行中：0
- 暂停：0
- 待规划：0

## 流程合规说明
> **合规标记**（RQ-037起强制）：
> - ✅ = 通过 | ❌ = 未执行 | ⬜️ = 豁免（需备注原因）
> - 5项：Brainstorming → Plan → Branch → Review → Validation
> - RQ-036及之前的需求不追溯

## 需求跟踪矩阵
| 需求编号 | 需求名称 | 规格文件 | 计划文件 | 合规 | 状态 |
|---------|---------|---------|---------|------|------|

## 执行时间线
### 2026-xx-xx
- 🎉 项目初始化完成（v10状态机版）
```
