设计特点说明

  • 内联展示 - API 请求/响应内容直接在对话过程中展示，不使用模态框
  • 展开/收起 - 点击步骤标题可以展开或收起详细内容
  • 状态指示 - 使用图标和颜色清楚指示每个步骤的执行状态
  • 代码样式 - 请求/响应使用等宽字体，专业易读
  • 左边界颜色 - API 请求用蓝色，响应用绿色，工具调用用紫色
