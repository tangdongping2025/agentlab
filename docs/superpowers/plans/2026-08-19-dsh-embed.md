# dsh 单独部署 + 前端 iframe 集成 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 ECS 宿主机部署 DeepSeek Harness (dsh web，GLM-4.7 后端)，经 nginx 独立端口反代，context-lab 前端以 iframe 型智能体入口载入。

**Architecture:** dsh 跑 ECS 宿主机 systemd（与容器生命周期解耦，Watchtower 零影响）；宿主机 nginx 监听 3080 反代 127.0.0.1:3081（token query 校验 + WebSocket 透传）；后端注册 `dsh` iframe 型 agent（仅元数据，无 run 循环）；前端 `AgentWorkspace` 按 `workspace.type === 'iframe'` 分发到新组件 `IframeWorkspace`。

**Tech Stack:** dsh (`npx -y @deepseek-ai/dsh web`) / systemd / nginx / FastAPI registry / React+TS+Vitest。

**Spec:** `docs/superpowers/specs/2026-08-19-dsh-embed-design.md`

## Global Constraints

- ECS 访问只用 paramiko 模式（Windows 本机无 sshpass）：`ssh root@47.97.66.45`，密码经 `ECS_PWD` 环境变量，单条 Bash 命令内联 `export ECS_PWD='...'`（调用间不持久）。
- 任何密钥/token 输出必须 mask（如 `1fe959****06rD`）；mask 判断禁用 `${X:-}`，用 `[ -n "$X" ]`。
- GLM key 只存 `/root/.dsh/glm_key` 与 `/root/.dsh/glm_key.env`（600 权限），不进仓库、不回显。
- 前端验证基准：`npx vitest run` 全绿（38 文件/361 测试，见 memory preexisting-failing-tests）；后端验证用不依赖 DB 的子集。
- 部署薄 patch 链路参考 memory `project_ecs-access`（既有 ecs_*.py paramiko 脚本模式）。

### Task 3: 宿主机 nginx 反代（token + WebSocket）

**Files:**
- Create（ECS 宿主机）: `/etc/nginx/conf.d/dsh.conf`
- Create（仓库，防丢失备份）: `deploy/dsh-nginx.conf`（占位符 `<TOKEN>` 版）

**Interfaces:**
- Consumes: dsh `127.0.0.1:3081`（Task 2）。
- Produces: `curl -H none http://47.97.66.45:3080/` → 403；带 `?token=<TOKEN>` → 200。TOKEN 值供 Task 6 的 `DSH_IFRAME_URL`。

- [ ] **Step 1: 生成 token + 写 nginx 配置**

```bash
TOKEN=$(openssl rand -hex 12); echo "TOKEN=$TOKEN" > /root/.dsh/nginx_token   # 600
yum install -y nginx || true
cat > /etc/nginx/conf.d/dsh.conf <<EOF
map \$http_upgrade \$connection_upgrade { default upgrade; '' close; }
server {
    listen 3080;
    server_name _;
    location / {
        if (\$arg_token != "$TOKEN") { return 403; }
        proxy_pass http://127.0.0.1:3081;
        proxy_http_version 1.1;
        proxy_set_header Upgrade \$http_upgrade;
        proxy_set_header Connection \$connection_upgrade;
        proxy_set_header Host \$host:\$server_port;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }
}
EOF
nginx -t && systemctl enable --now nginx && systemctl reload nginx
```

（若 Task 1 勘察发现宿主机 3080 已被占：外露端口改 3082，同步改 unit 的 `--trusted-host` 并 `systemctl restart dsh-web`。）

`IframeWorkspace.tsx`（容器链：AgentRuntimeView 主区 `flex:1 minHeight:0`，根元素用 flex 填满）：

import React from 'react';
import { useAgentRuntimeStore } from '../../stores/agentRuntimeStore';

const linkStyle: React.CSSProperties = {
  position: 'absolute', top: 8, right: 8, zIndex: 1,
  padding: '4px 10px', borderRadius: 999, fontSize: 12,

        title="DeepSeek Harness"

import React from 'react';
