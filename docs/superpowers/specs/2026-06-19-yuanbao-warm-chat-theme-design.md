# 元宝暖白聊天主题设计

## 背景

当前 AgentRuntime 主工作台已经默认进入 Claude SDK 对话窗口，并完成 AI 回复文章卡浅色化，但整体界面仍混用原有深色/冷色变量。用户提供了元宝 Web UI 暖白浅色聊天 CSS，希望参考其聊天窗口风格，让默认工作台更接近日常聊天工具的阅读体验。

## 目标

将 AgentRuntime 主工作台调整为局部暖白聊天主题：中间聊天区、AI/用户消息、输入区、侧栏、状态栏和 Markdown 内容形成统一的暖白浅色视觉。

## 范围

- 覆盖 AgentRuntime 主工作台相关 UI：`AgentRuntimeView`、`ChatWorkspace`、`MessageBubble`、`Markdown`、`CodeBlock`、`AgentLibrary`、`AssistantSidebar`、`ObservabilityBar`。
- 页面和聊天区底色参考 `#F5F1EB`。
- 侧栏和状态栏使用暖灰/白色卡片色，避免与聊天区割裂。
- AI 回复卡使用白底、深色正文、轻阴影和 12px 圆角。
- 用户消息使用米灰底、深色文字和右侧气泡形态。
- 输入框使用白底、暖灰边框和圆角。
- 发送按钮保留蓝色主色，但形态更圆润。
- Markdown 引用块、表格、链接、inline code 和代码块同步适配暖白主题。

## 非目标

- 不改历史页。
- 不改设置弹窗。
- 不新增主题切换设置。
- 不引入全局 ThemeProvider。
- 不改后端、提示词、agent runtime 或会话数据结构。
- 不使用全局 `!important` 覆盖。

## 设计

采用“局部主题 token + 组件内小幅替换”的实现方式。在 AgentRuntime 相关组件中使用一组暖白色值，替换当前依赖冷色/深色变量的关键区域。这样可以让主工作台快速获得一致的元宝式暖白观感，同时避免全站换肤带来的回归风险。

关键色值：

- 主聊天背景：`#F5F1EB`
- 侧栏背景：`#EDE8DF`
- AI 卡片背景：`#FFFFFF`
- 用户气泡背景：`#E8E2D9`
- 暖灰边框：`#D6CFC4`
- 主文字：`#1A1A1A`
- 次级文字：`#555555`
- 主按钮/链接：`#2563EB`
- 滚动条滑块：`#C8C1B6`

组件调整：

- `AgentRuntimeView`：外层容器使用暖白底色。
- `ChatWorkspace`：聊天面板、消息滚动区和输入区使用暖白/白色；输入框圆角提升到接近聊天应用形态；发送按钮保留蓝色。
- `MessageBubble`：AI 回复卡使用白底文章卡；用户消息使用米灰底深色文字，右侧气泡圆角参考元宝样式。
- `Markdown`：正文保持清晰行高，blockquote 改暖灰左边线，链接蓝色，表格表头改暖灰浅底，inline code 使用浅暖灰。
- `CodeBlock`：保持深色代码块，背景对齐 `#1E1E1E`，圆角 8px。
- `AgentLibrary`、`AssistantSidebar`、`ObservabilityBar`：展开态和收起窄条统一为暖灰/白色，边框使用暖灰色。

## 验收

- 默认进入 Claude SDK 工作台后，主界面呈现暖白浅色聊天体验。
- 左右侧栏默认收起仍生效，展开后视觉与主聊天区一致。
- AI 回复卡为白底，正文深色可读，重点加粗仍明显。
- 用户消息为米灰底深色文字。
- 输入框为白底暖灰边框，发送按钮为蓝色。
- Markdown 引用块、表格、链接和代码块在暖白主题下可读。
- 状态栏默认摘要仍展示当前智能体、状态、消息数、能力、目录和 Token 状态。
- 不影响历史页和设置弹窗。
