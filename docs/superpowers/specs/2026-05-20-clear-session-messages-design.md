# RQ-033：增加清除会话信息的功能

## 问题定义

用户需要清除当前会话的消息记录以重新开始对话，但目前只能通过"新建对话"间接实现（创建新会话 + 切换），无法在当前会话内直接清空消息。

store 中已有 `clearHistory()` 方法和 `agentService.clearHistory()` 方法，但无任何 UI 入口调用它们。

## 需求范围

- 在对话区域增加"清除对话"操作入口
- 点击后弹出确认提示（防误操作）
- 确认后清空当前会话的消息、时间线、agent 内部状态
- 清空后自动保存到 localStorage
- 清空后显示 WelcomePage（与无消息时的初始状态一致）

## 不做的事

- 不做"清除单条消息"功能（本次只做全量清除）
- 不做"清除所有会话"功能（只清除当前会话）
- 不改变已有的新建对话、删除会话功能

## 用户交互流程

1. 用户在对话区域找到"清除对话"按钮
2. 点击后弹出确认提示（非 alert，使用内联确认）
3. 用户确认 → 消息清空 → 显示 WelcomePage
4. 用户取消 → 无操作

## 按钮位置

放在 ChatInteraction 输入区域左下角（与文件附件按钮同行），使用 🗑️ 图标，小尺寸、低存在感，不干扰主流程。

## 技术方案

调用链路：
1. `useAppStore.getState().clearHistory()` — 清空 store 中的 conversationHistory
2. `useAppStore.getState().resetTimeline()` — 重置时间线步骤
3. `agentService.clearHistory()` — 清空 agent 内部对话历史、缓存、计数
4. `useAppStore.getState().saveCurrentSession()` — 持久化空消息列表

确认提示：使用组件内 state 控制的内联确认弹层（小气泡），不使用 window.confirm。

## 设计理念合规检查

| 原则 | 合规性 |
|------|--------|
| 极简 | 单按钮 + 确认气泡，无额外 UI |
| 专注 | 不与新建对话混淆，清除是在当前会话内操作 |
| 直觉 | 🗑️ 图标自解释，确认防误操作 |
| 一致性 | 与现有删除按钮风格一致 |
| 工匠精神 | 确认气泡定位精准，动画流畅 |
