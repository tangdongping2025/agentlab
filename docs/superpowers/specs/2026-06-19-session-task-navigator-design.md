# RQ-057 会话内任务浮层目录设计

## 背景

一次智能体会话中可能包含多个用户任务。当前聊天窗口按时间线展示消息，用户想回看某个任务时只能滚动查找，长会话中定位成本较高。

## 目标

在 AgentRuntime 主工作台聊天窗口中增加会话内任务浮层目录，让用户快速查看本会话中的用户提问，并点击定位到对应的原始用户消息。

## 范围

- 仅覆盖 `claude-sdk` 等工作台聊天窗口使用的 AgentRuntime 主工作区。
- 任务从当前 `workspaceMessages` 中派生，不新增后端接口或数据库字段。
- 仅识别 `role === 'user'` 的消息；用户主动发出的每条消息都视为一次任务。
- 任务目录以右侧可收起浮层形式显示在聊天窗口内。
- 点击任务项滚动到对应用户消息，并短暂高亮该消息。

## 非目标

- 不做跨会话任务检索。
- 不自动关联后续 AI 回复作为任务结果。
- 不提供任务编辑、删除、状态、完成度或持久化任务管理。
- 不使用 LLM 抽取任务。
- 不修改 MySQL schema、后端 API、agent prompt、历史页或设置弹窗。

## 任务识别规则

采用最简单稳定的前端规则：用户主动发出的每条消息都进入任务目录。

识别对象：

- 只扫描 `workspaceMessages`。
- 只处理 `role === 'user'` 的消息。

识别条件：

- 每条用户消息都视为一次任务。
- `assistant` 消息不进入任务目录。

标题生成：

- 从原始用户消息首行生成短标题。
- 去除首尾空白。
- 超过固定长度时截断并追加省略号。
- 保留原始消息作为跳转目标，不复制完整内容到任务目录。

## 交互设计

聊天窗口右上区域增加任务入口按钮：

- 有任务时显示 `任务 N`。
- 无任务时显示 `任务 0`。
- 点击后展开或收起右侧任务浮层。

任务浮层：

- 展开宽度控制在 180-220px。
- 使用元宝暖白主题：暖灰浮层、白色任务项、蓝色强调。
- 空态显示“本会话暂无用户任务”。
- 每个任务项显示序号、短标题、位置提示，例如“第 3 条用户任务”。

定位行为：

- 点击任务项后滚动聊天消息视口到对应用户消息。
- 目标消息居中显示。
- 目标消息短暂高亮，帮助用户确认定位结果。
- `MessageBubble` 不承担定位职责，由 `ChatWorkspace` 在消息外层包装定位容器。

## 组件与数据流

新增轻量组件 `SessionTaskNavigator`：

- 接收当前消息列表。
- 从消息列表派生任务列表。
- 渲染任务入口、展开浮层、任务项和空态。
- 点击任务项时回调 `ChatWorkspace`。

新增纯函数 `deriveSessionTasks(messages)`：

- 输入当前消息数组。
- 输出任务数组，包含任务 id、消息 index、标题和序号。
- 不访问 Zustand、不访问 DOM、不访问后端。

`ChatWorkspace` 负责：

- 给每条消息外层提供可定位容器。
- 保存最近被定位的 message index。
- 执行 `scrollIntoView({ block: 'center' })`。
- 对被定位消息应用短暂高亮样式。

## 边界处理

- 历史会话恢复后，任务目录由已加载消息自动派生。
- 新消息发送后，任务目录自动更新。
- streaming 中的 assistant 内容不参与任务识别。
- 不做语义判断，避免漏掉委婉表达的用户请求。
- 用户消息很短也进入任务目录。

## 测试策略

- 单元测试 `deriveSessionTasks(messages)`：
  - 每条用户消息生成任务。
  - assistant 消息不生成任务。
  - 多个用户任务保留正确 message index。
  - 长标题被截断。
- 组件测试 `SessionTaskNavigator`：
  - 有任务时显示 `任务 N` 和任务标题。
  - 无任务时展开显示空态。
  - 点击任务项触发跳转回调。
- 集成测试 `ChatWorkspace`：
  - 渲染工作台消息后显示任务入口。
  - 点击任务项会调用目标消息的滚动定位。
  - 目标消息获得高亮标识。
- 回归测试：
  - 不破坏现有 `ChatWorkspace`、`MessageBubble`、默认工作台和元宝暖白主题测试。

## 验收标准

- 一个会话中有多条用户消息时，聊天窗口可展开右侧任务目录。
- 任务目录展示所有用户消息，普通问答也作为用户任务列入。
- 点击任务项能快速定位到原始用户消息。
- 无任务时有清晰空态，不影响正常聊天。
- 不新增后端或数据库改动。
