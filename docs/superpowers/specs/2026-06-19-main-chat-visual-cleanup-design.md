# RQ-058 主聊天视觉清理设计

## 背景

RQ-057 验收过程中发现主聊天体验还有三处不协调：聊天窗口中显示工具调用流水、代码/文本块黑底过重、主界面部分头部区域仍偏黑。

## 目标

让 AgentRuntime 主聊天界面保持暖白阅读体验，减少与普通对话无关的技术流水，并降低代码块和头部区域的黑色突兀感。

## 范围

- 主聊天窗口不再直接展示 `workspaceEvents` 工具调用流水。
- Markdown 代码块从深色主题改为暖白浅色主题。
- AgentRuntime 相关头部/标签区域避免使用深色底色，统一为暖白/白色系。

## 非目标

- 不删除 observability 数据，底部观测栏仍可展示运行步骤。
- 不改 agent 执行、工具调用、后端或数据库。
- 不改 Markdown 输出规范。

## 验收标准

- 聊天消息区不再出现“调用工具: Skill / Workflow / WebSearch / WebFetch”一类流水列表。
- 代码块背景不再是大面积黑底，与暖白聊天卡片协调。
- 主界面头部/小标签不再使用黑色底色。
- 现有暖白主题、任务目录和主工作台默认布局不回退。
