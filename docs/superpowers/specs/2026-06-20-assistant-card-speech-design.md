# Assistant 卡片语音播放设计

## 背景

当前智能体回复以 assistant 卡片呈现，卡片操作区已有“复制内容”“复制纯文本”“重新生成”。用户希望在单张回复卡片上增加播放按钮，点击后朗读该卡片内容。

## 范围

- 仅支持 assistant 回复卡片。
- 仅支持用户手动点击单张卡片播放。
- 不做自动朗读最新回复。
- 不做跨卡片连续播放。
- 不接入云端 TTS，不生成音频文件。

## 方案

使用 Chrome 支持的浏览器 Web Speech API：`window.speechSynthesis` 和 `SpeechSynthesisUtterance`。朗读内容复用现有 Markdown 转纯文本逻辑，避免读出 Markdown 标记、表格分隔线和代码反引号。

## 交互

- 每张 assistant 卡片操作区新增“朗读”按钮。
- 点击“朗读”播放当前卡片纯文本。
- 当前卡片播放中，按钮显示“停止”。
- 播放中再次点击“停止”会停止当前朗读。
- 点击另一张卡片“朗读”时，先停止已有朗读，再播放新卡片。
- 流式输出中的临时 assistant 卡片继续不显示操作区，因此不显示朗读按钮。
- 浏览器不支持 Web Speech API 时隐藏朗读按钮。

## 验收标准

- Chrome 中点击 assistant 卡片“朗读”按钮，可以朗读该卡片内容。
- 朗读文本不包含常见 Markdown 语法噪音。
- 同一时间只有一张卡片处于播放状态。
- 停止按钮可以中止朗读。
- 现有复制、复制纯文本、重新生成行为不受影响。

## 测试

- 单元测试覆盖 assistant 卡片显示朗读按钮。
- 单元测试覆盖点击朗读会调用 `speechSynthesis.speak`。
- 单元测试覆盖播放中点击停止会调用 `speechSynthesis.cancel`。
- 单元测试覆盖不支持 Web Speech API 时不显示朗读按钮。
