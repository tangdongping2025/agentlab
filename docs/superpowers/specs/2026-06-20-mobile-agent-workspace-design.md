# Agent 工作区移动端适配设计

## 目标

让龙虾 Agent 工作区在手机窄屏浏览器中尽量可用，重点保证 `对话 / 文件 / Skill / MCP` tab 可切换、面板内容不横向撑破页面、长路径和长参数可读。

## 范围

- 顶部 tab 栏支持小屏横向滚动，避免四个 tab 挤压或溢出外层。
- `SkillPanel` 与 `McpPanel` 卡片在窄屏下保持单列纵向展示。
- 长路径、skill 内容、MCP selectedArgs 在卡片内换行或滚动，不撑破页面。
- 保持桌面端现有视觉和布局，不重做整体移动端导航。

## 非目标

- 不重构整个应用为 mobile-first。
- 不改变 ChatWorkspace、FilesPanel 的业务逻辑。
- 不新增响应式路由或底部导航。

## 验收

- 360px 宽度下 tab 栏可横向滚动，`MCP` tab 可点击。
- 360px 宽度下 Skill/MCP 卡片宽度不超过容器。
- 长路径和长参数不会导致页面整体横向溢出。
- 桌面宽度下原布局不退化。
