# @ 文件引用选择设计

## 背景

用户在对话中提到文件时，希望 Agent 能明确知道目标文件。直接把文件全文塞进消息会污染上下文，自动猜文件名又不够可控，因此采用 `@` 触发的显式文件引用选择。

## 范围

- 在对话输入区输入 `@` 后展示当前工作目录下的文件候选。
- 用户继续输入关键词时过滤候选，选择后在输入内容中插入 `@相对路径`。
- 发送消息时将已选择的文件路径作为轻量上下文提示交给 Agent 按需读取。
- 第一版不读取文件全文、不做复杂索引、不支持二进制预览、不改变文件安全校验逻辑。

## 验收

- 输入 `@` 会出现文件候选列表。
- 选择文件后输入框中出现 `@path/to/file.ext`。
- 发送消息时请求内容包含“用户提到以下当前工作区文件”的路径提示。
- 发送后清空本轮已选文件引用。
