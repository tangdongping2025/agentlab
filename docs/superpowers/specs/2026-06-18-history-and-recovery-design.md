# 历史与恢复

## 需求

历史页从“历史会话查询页”调整为“历史与恢复”，帮助用户从已有 agent session 中找回上下文并继续工作。当前阶段不把 session 等同于任务，也不新增 Task 或 Task Segment 数据模型。

## 设计

- 页面标题改为“历史与恢复”，副文案说明可查看并继续 agent 会话上下文。
- 筛选区保留关键词、agent、日期和查询入口；token 筛选弱化为高级筛选或更清晰的中文文案。
- 左侧列表保持 session 列表语义，但展示成可恢复上下文卡片：名称、agent、preview、更新时间和 token 辅助信息。
- 右侧详情顶部增加会话信息卡片，展示会话名、agent、更新时间、token 和 sessionId 短码。
- 恢复主按钮文案改为“继续这个上下文”，沿用现有恢复逻辑。

## 不做

- 不新增 Task 表。
- 不做 Task Segment。
- 不做自动标题或自动摘要。
- 不改变 session 持久化与恢复语义。

## 验收

- 历史页标题和文案体现“历史与恢复”。
- 用户选择 agent session 后，右侧先看到会话信息卡片，再看到消息详情。
- agent session 可通过“继续这个上下文”恢复到工作区。
- 非 agent session 不显示继续入口。
- 现有恢复逻辑和历史详情消息时间显示不回归。
