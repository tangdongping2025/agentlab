# 应用库智能体名称视觉设计

## 背景

左侧应用库中的智能体名称当前识别度不足，且 `Claude SDK Agent` 是偏实现层的技术名称，不适合作为面向用户的默认智能体名称。

## 设计

- 应用库展开后，智能体名称使用蓝紫渐变文字，渐变值与顶栏 `AGENT LAB` 图标保持一致：`linear-gradient(135deg, var(--accent-blue), var(--accent-violet))`。
- 仅调整智能体名称文字，不修改卡片布局、描述、工作区类型 badge 或收起态应用库。
- `claude-sdk` 智能体显示名改为 `龙虾 Agent`，保留其 id、能力、工作区类型和描述不变。

## 验收

- 应用库展开后，智能体名称使用蓝紫渐变样式。
- `claude-sdk` 在应用库和新建会话名称中显示为 `龙虾 Agent`。
- `claude-sdk` 仍是默认选中的主要智能体。
