# 历史会话详情任务定位设计

## 背景

历史会话详情内容变清晰后，长会话仍需要快速定位用户发起的任务。对话窗口已经有会话任务列表，历史详情应复用同一套任务识别规则。

## 范围

- 只影响 `HistoryPage` 的会话恢复详情区。
- 复用 `SessionTaskNavigator` / `deriveSessionTasks`，不重新实现任务识别规则。
- 点击任务后滚动到对应历史消息，并短暂标记该消息为当前定位目标。
- 任务入口放在会话信息卡片内的“继续这个上下文”下方。
- 不改变历史查询、继续上下文、历史洞察和沉淀库逻辑。

## 验收

- 打开含多条用户消息的历史会话时，详情区显示任务入口，任务数量与用户消息数量一致。
- 展开任务列表并点击任务后，详情区滚动到对应消息，任务列表收起，对应任务进入选中态。
