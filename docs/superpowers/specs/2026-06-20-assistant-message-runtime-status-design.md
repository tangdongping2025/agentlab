# Assistant 消息内运行状态与工具时间线设计

## 目标

在龙虾 Agent 正在生成的 assistant 消息卡片顶部显示本轮状态，并在同一消息卡片内部折叠展示本轮工具调用时间线。

## 范围

- 底部全局状态栏保持不变，不新增独立状态条。
- 仅增强当前 streaming assistant 消息卡片；历史消息暂不回填工具时间线。
- 复用现有 `workspaceEvents`，不改变后端 SSE 协议。
- 工具时间线展示 `tool_call` / `tool_result`，默认折叠，用户可展开查看详情。

## 验收

- 龙虾 Agent 运行时，当前 assistant 卡片顶部显示类似 `龙虾 Agent · 正在执行命令…`。
- 工具调用以该 assistant 卡片内部的折叠时间线展示，而不是单独漂浮在消息列表中。
- 底部输入区和全局状态职责不变。
