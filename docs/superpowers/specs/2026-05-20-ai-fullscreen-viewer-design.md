# RQ-034：AI 回复全屏查看功能

## 问题定义

AI 回复内容较长时，在对话气泡中（maxWidth: 75%）阅读受限，缺少沉浸式阅读模式。

## 需求范围

- 在 AI 回复气泡上增加全屏按钮（与 💾 保存按钮并列）
- 点击后弹出全屏模态层，展示该条消息的 Markdown 渲染内容
- 全屏模态层支持 ESC 关闭 + 关闭按钮
- 全屏内容可滚动，适配长文

## 不做的事

- 不做完整对话记录的全屏展示（只做单条消息）
- 不做全屏模式下的编辑功能
- 不做全屏模式的目录/大纲导航

## 用户交互流程

1. 用户在 AI 回复气泡右上角看到 🔍 全屏按钮（hover 显现，与 💾 一致）
2. 点击 → 全屏模态层覆盖整个页面，居中显示 Markdown 内容
3. 按 ESC 或点击关闭按钮 → 关闭模态层，回到对话

## 技术方案

- 新增 `FullscreenViewer` 组件：全屏模态层，接收 content 字符串，用 MarkdownRenderer 渲染
- MessageBubble 中增加 🔍 按钮，点击设置 `fullscreenContent` state
- ChatInteraction 管理 fullscreenContent state，渲染 FullscreenViewer
- 键盘事件监听 ESC 关闭

## 设计理念合规检查

| 原则 | 合规性 |
|------|--------|
| 极简 | 按钮hover显现，模态层只有内容+关闭，无冗余 |
| 专注 | 全屏模式专注阅读，无干扰元素 |
| 直觉 | 🔍 图标自解释，ESC 关闭符合习惯 |
| 一致性 | 按钮样式与 💾 一致，模态层与现有 Modal 风格一致 |
| 工匠精神 | 模态层动画流畅，内容排版舒适 |
