# 智能体新用户体验优化设计

## 背景

服务即将发布给更多用户使用，当前聊天工作区缺少空状态引导，错误消息直接暴露为 `[错误] ...`，龙虾 Agent 运行时的工具过程在主对话区不可见，容易让用户误以为没有响应。

## 设计

本次只做前端可见体验层优化，不改变后端 agent 能力、SSE 协议或工具执行逻辑。

1. 空对话时显示欢迎卡，说明当前智能体能做什么，并提供 3 个示例按钮。点击示例按钮直接发起该示例请求。
2. workspace 运行失败时，assistant 消息使用产品化错误文案：先告诉用户发生了什么、下一步怎么做，再保留简短技术详情。
3. 龙虾 Agent 运行时，在主对话区显示一条轻量过程状态，不恢复完整工具流水；状态从最近事件推导，例如查看文件、修改文件、执行命令、分析工具结果。

## 验收

- 空对话选择龙虾 Agent 时能看到欢迎语和示例按钮。
- 点击示例按钮会调用 `runWorkspace` 发送对应示例内容。
- 运行失败时不再只显示 `[错误] ...`，而是显示可读的失败说明和技术详情。
- 龙虾 Agent 运行中有工具事件时，主对话区显示当前过程状态；其他历史工具事件不作为完整流水展示。
