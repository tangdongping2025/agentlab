# RQ-013 会话列表显示优化

## 目标

侧栏每个会话项显示"开始时间 · 第一句话"，替代当前的"会话名 + 相对更新时间"，让用户快速识别每个会话的内容。

## 当前行为

每个会话项显示：
- `session.name`（如"🍽️ 餐厅预订"）
- `formatRelativeTime(session.updatedAt)`（如"2h"、"3d"），靠右小字

## 新行为

每个会话项显示：
- `formatSmartTime(session.createdAt)` · 首句截断（20字符，超出加 `...`）

### 时间格式（智能混合）

| 条件 | 格式 | 示例 |
|------|------|------|
| 今天 | HH:mm | 14:30 |
| 今年但非今天 | MM-DD HH:mm | 05-12 09:15 |
| 跨年 | YYYY-MM-DD | 2025-12-01 |

### 首句规则

| 条件 | 显示 |
|------|------|
| 有消息 | `messages[0].content` 截断 20 字符，超出加 `...` |
| 无消息 | 显示"新对话" |

### 显示示例

- `14:30 · 测试持久化消息...`
- `05-12 09:15 · 你是一个专业的餐厅预...`
- `14:30 · 新对话`

## 受影响文件

| 文件 | 变更 |
|------|------|
| `src/components/SessionList.tsx` | 替换会话项渲染逻辑，新增 formatSmartTime，删除 formatRelativeTime |

## 不变的部分

- 会话高亮（蓝色左边框 + 背景色）
- 删除按钮（hover 显示 ×）
- 折叠逻辑
- "更多"分页（VISIBLE_COUNT = 10）
- 点击切换会话
- Session 类型、sessionService、store — 均不修改

## 乔布斯设计理念合规检查

| 原则 | 合规 |
|------|------|
| 极简 | ✅ 单行信息密度提升，无多余元素 |
| 专注 | ✅ 帮助用户快速找到目标会话 |
| 直觉 | ✅ 时间+首句是用户识别会话的自然方式 |
| 一致性 | ✅ 沿用现有侧栏样式体系 |
| 工匠精神 | ✅ 智能时间格式，空会话有占位处理 |
