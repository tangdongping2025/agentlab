# Assistant 卡片复制纯文本设计

## 背景

原始 Markdown 适合复制到支持 Markdown 的工具，但直接分享给微信、邮件、普通文档时可读性差。

## 设计

保留“复制内容”按钮用于复制原始 Markdown。新增“复制纯文本”按钮，将 assistant 回复内容转换为更适合普通阅读的纯文本后写入剪贴板。

转换规则保持简单稳定：

- 标题去掉 `#` 前缀。
- 粗体、斜体、删除线去掉 Markdown 标记。
- 链接 `[文本](url)` 转为 `文本（url）`。
- 代码块去掉围栏标记，保留代码内容。
- 行内代码去掉反引号。
- 表格分隔行删除，普通表格行用 tab 分隔。
- 列表保留项目符号文本。

## 验收

- assistant 卡片默认显示“复制内容”和“复制纯文本”。
- “复制内容”仍复制原始 Markdown。
- “复制纯文本”复制转换后的纯文本。
- `showActions=false` 时两个复制按钮都不显示。
- “重新生成”保持原有行为。
