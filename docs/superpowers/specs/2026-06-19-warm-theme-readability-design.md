# 暖白主题可读性修复设计

## 背景

界面已切换为暖白外壳，但全局 CSS token 仍是暗色主题，导致多个组件在暖白背景上出现低对比、字号过小、文字发灰的问题。文件面板尤其明显。

## 范围

- 将 `src/index.css` 的全局颜色 token 调整为暖白主题下可读的浅底深字体系。
- 增强 `FilesPanel` 的文件列表、路径、空状态、代码预览区域可读性。
- 不改变文件面板的数据加载、目录切换、数据库持久化和文件安全校验逻辑。

## 验收

- 全局 `--text-primary` / `--text-secondary` / `--text-tertiary` 在暖白背景下为深色可读文本。
- 文件列表背景为浅色，文件名不低于 14px，时间/大小不低于 12px。
- 当前路径、空状态、加载状态不再使用过淡文字。
- 文件预览区域为浅底深字或具备足够对比度。
