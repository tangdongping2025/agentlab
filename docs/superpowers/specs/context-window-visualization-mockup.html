💡 学习要点
系统提示词：定义角色和任务，占用 ~30% 的上下文空间
对话历史：累积最多，占 ~40%，是优化重点
Token 计算：大致等于 字符数 ÷ 4（中文1字符≈1 token）

📚 学习笔记

  • • 上下文窗口越大，能记住的对话历史就越多
  • • 每个 API 请求都包含完整的上下文，不是增量的
  • • Token 是计费单位，优化策略可以降低成本
  • • 滑动窗口通过限制消息数量来控制上下文大小
