# 历史会话可读性与卡片风格设计

## 背景

当前历史会话页信息层级弱、列表和详情都偏调试页样式，长历史内容基本看不清楚。用户希望历史会话功能全面优化，卡片风格与主对话窗口保持一致。

## 设计

只优化前端呈现，不改后端接口、数据模型和恢复语义。

- 页面底色、卡片底色、边框和圆角沿用当前 ChatWorkspace 的暖白风格。
- 顶部标题区改为更清晰的“历史会话 / 找回上下文并继续工作”。
- tab 改成胶囊式导航，当前 tab 使用蓝色主色突出。
- 搜索筛选区改为独立浅色卡片。
- 左侧会话列表改为卡片式列表：标题、Agent badge、预览、时间信息分层展示；选中项使用蓝紫边框和浅底色。
- 右侧详情改为聊天阅读模式：会话信息卡 + 用户/助手消息卡片，消息样式接近 ChatWorkspace 的阅读卡片。
- 历史洞察和沉淀库继续保留现有功能，但卡片视觉统一到同一套暖白卡片风格。

## 不做

- 不新增后端字段。
- 不改查询、恢复和洞察算法。
- 不引入新依赖。
- 不改主对话窗口组件结构。

## 验收

- 历史页整体底色、面板、列表、详情呈现为暖白卡片风格。
- 会话列表标题、预览、Agent、时间明显分层，选中项清晰。
- 会话详情消息不再是裸文本，用户/助手内容以可读卡片呈现。
- “继续这个上下文”仍可用，历史洞察和沉淀库功能不回归。
