# 主界面默认工作台模式优化设计

## 背景

当前主界面启动后左右侧边栏默认展开，中间对话区被压缩；默认智能体来自接口返回的第一个 agent，不一定是最常用的 Claude SDK Agent。底部状态栏在空闲默认状态下主要显示 Token `0/0`、步骤 `0` 等低价值信息，视觉上占位但信息密度不足。

## 目标

让应用默认启动后直接进入“可对话”的主工作台状态：中间 Claude SDK Agent 对话窗口最大化呈现，左右侧边栏收起，底部状态栏展示当前工作台的关键有效信息。

## 范围

- 默认选中 `claude-sdk` 智能体；如果接口未返回该智能体，则回退到第一个可用智能体。
- 左侧应用库默认收起，只保留可展开窄条。
- 右侧项目助手默认收起，只保留可展开窄条。
- 底部状态栏默认收起态展示：当前智能体、运行状态、消息数、能力/工具、工作目录或默认沙箱、Token 状态。
- 保留用户手动展开/收起侧边栏能力。
- 不做布局持久化。
- 不新增设置项。
- 不改后端接口、agent runtime、会话持久化或状态栏展开态三栏内容。

## 设计

### 默认智能体

`agentRuntimeStore.loadAgents()` 在首次加载且 `currentAgentId` 为空时优先选择 `claude-sdk`。如果不存在 `claude-sdk`，使用接口返回的第一个 agent。已有 `currentAgentId` 时不覆盖用户选择。

### 侧边栏默认状态

`AgentLibrary` 和 `AssistantSidebar` 的本地 `collapsed` 初始值从 `false` 改为 `true`。展开按钮、收起按钮、宽度调节和现有内容保持不变。

### 状态栏默认摘要

`ObservabilityBar` 收起态从“Token 0/0 + 步骤 0”为主，改为信息胶囊式摘要：

- 当前目标：当前智能体名称 + 工作台。
- 状态：空闲/运行中。
- 消息：当前工作台消息数量。
- 能力：显示当前 agent 的 `capabilities` 前 4 项；无能力时显示“无工具”。
- 工作目录：有 `workspaceCwd` 时显示路径尾部；没有时显示“默认沙箱”。
- Token：有消耗时显示 `input/output`；没有消耗时显示“等待首次运行”。

展开按钮和目标下拉保留，展开后仍显示运行步骤、Token 消耗、策略效果三栏。

## 验收

- 首次加载 agent 后默认选中 `claude-sdk`。
- 主界面默认左侧应用库和右侧项目助手均为收起窄条。
- 用户仍可手动展开左右侧边栏。
- 状态栏默认收起态能看到当前智能体、空闲/运行中、消息数、能力、工作目录/默认沙箱、Token 状态。
- 状态栏展开后原有三栏内容仍可用。
- 不影响历史会话恢复时的智能体选择。
